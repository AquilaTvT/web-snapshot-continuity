Fonts of the acmart class, copied so that a figure directory builds on its own.

LinLibertine_R.otf, LinLibertine_RI.otf, LinLibertine_RB.otf (font versions
5.3.0, 5.1.6, 5.1.4) and LinBiolinum_R.otf, LinBiolinum_RI.otf,
LinBiolinum_RB.otf (1.1.8, 1.1.3, 1.3.2): Linux Libertine O and Linux
Biolinum O by Philipp H. Poll, as distributed in TeX Live's libertine package.
They are free under the GNU General Public License with font exception
(GPL-libertine.txt) and additionally under the Open Font License; the
package's licence statement is LICENCE-libertine.txt. Both files are
unmodified copies from CTAN fonts/libertine/doc/.

LibertinusMath-Regular.otf: Libertinus Math 7.040, copyright (c) 2012-2021
The Libertinus Project Authors, licensed under the SIL Open Font License 1.1
(OFL.txt, the licence file of the libertinus-fonts package).

The fonts are unmodified. plot.py points XeTeX at this directory through the
OPENTYPEFONTS search path; nothing is installed system-wide.
