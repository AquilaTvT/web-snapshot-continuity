## Public revision audit

Six purposively selected English Wikipedia Web-topic pages were queried for the
2024 window through the public revisions API on 2026-11-04. Exact request URLs,
response bytes, SHA-256 digests, and collection times are retained in
`data/raw/revision-histories-2024/collection.json`. The set was fixed after an
exploratory World Wide Web request; it is not a random or preregistered sample.
The first return on each page was then fetched by 18 revision IDs for direct
source-byte comparison. Those unmodified texts and their CC BY-SA 4.0 attribution
are retained beside the metadata, in `ATTRIBUTION.md` and
`witness-collection.json`. All 131 recorded hash returns and six selected byte
witnesses are distinguished in the derived audit. Source revision identity is
not a rendered-page, cache, or deployment-history guarantee.
